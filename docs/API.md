# public.safe API reference

Generated by `publicsafe api-docs` from the FastAPI OpenAPI schema (REST) and
the WebSocket handlers; do not edit by hand. The live schema is served at
`/api/openapi.json` and browsable at `/api/docs`.

## Conventions

- Base URL `https://<host>:8443`. JSON bodies, timestamps ISO-8601 UTC with
  milliseconds.
- **Admin** routes need the `ps_admin` session cookie (from
  `POST /api/auth/login`) and, on every non-GET request, the header
  `X-Requested-With: publicsafe` (CSRF check).
- **Device** authentication happens only inside the `/ws/camera` `auth`
  message; device tokens never appear in URLs or headers.
- Every response carries `X-Request-ID` (a client may send its own, up to 64
  characters of `[A-Za-z0-9._-]`); the same id is in the server's JSON logs.
- Errors always have one shape:
  `{"error": {"code": "pin_invalid", "message": "...", "details": {}}}`.
  400 validation (`validation_error`, `details.fields`), 401 unauthenticated,
  403 forbidden / CSRF, 404 not found, 409 conflict, 410 gone, 423 locked,
  429 rate limited (with `Retry-After`), 500 internal (no stack trace).
- `TEST_MODE=1` adds `/api/test/*` (Playwright and fake-phone tests only); those
  routes are not listed here.

## WebSocket `/ws/camera` (phone -> server)

`wss://<host>:8443/ws/camera`, no cookie. Text frames are JSON, binary frames
are JPEG bytes. The first message must be `auth` within `WS_AUTH_TIMEOUT_S`
(5 s).

| Close code | Reason |
|---|---|
| 4000 | protocol error: `bad_json`, `bad_frame_meta`, `bad_ping`, `unknown_type`, `binary_without_meta` |
| 4001 | `auth_timeout`, `auth_invalid` or an unknown token |
| 4003 | camera revoked or session archived / deleted |
| 4004 | `superseded`: a newer connection for the same camera took over |
| 4008 | `rate_abuse`: more than 3x the target fps for `RATE_ABUSE_SECONDS` |
| 1009 | `frame_too_large` (above `MAX_FRAME_BYTES`) |
| 1011 | `server_error` |

| Direction | `type` | Fields | Notes |
|---|---|---|---|
| phone -> server | `auth` | `token`, `client: {ua, w, h, remember}` | first message |
| server -> phone | `hello` | `camera_id, camera_name, settings, server_time_ms, ack_every` | `settings` = `{target_fps, jpeg_quality, max_long_edge, confidence, privacy_mode}` |
| phone -> server | `frame_meta` | `seq` (int), `t_phone_ms`, `w`, `h` (int) | followed by exactly one binary JPEG |
| phone -> server | binary | JPEG bytes | |
| server -> phone | `ack` | `seq, t_server_recv_ms, processed_seq, dropped_replaced, dropped_ratelimit` | every `ack_every` frames |
| phone -> server | `ping` | `t_phone_ms, last_rtt_ms` (null at first) | every 5 s; feeds the clock-offset estimate |
| server -> phone | `pong` | `t_phone_ms, t_server_ms` | immediately |
| phone -> server | `pause` / `resume` | - | status `paused` / `online` |
| server -> phone | `settings` | `settings` | after an admin change |
| server -> phone | `error` | `code, message` | before a close when useful |

## WebSocket `/ws/dashboard` (server -> browser)

Needs the admin cookie. Without it the server accepts, sends
`{"type": "error", "code": "unauthenticated"}` and closes with 4001, so the
browser can read the code.

| Direction | `type` | Fields |
|---|---|---|
| browser -> server | `subscribe` | `camera_ids: [...] or "all"`, `preview_fps` (1-30, default 10); answered with one `camera_status` per camera and a `metrics` message |
| browser -> server | `unsubscribe` | `camera_ids: [...] or "all"` |
| server -> browser | `frame_result` | `camera_id, seq, t_server_recv_ms, t_processed_ms, w, h, detections: [{bbox, conf, anchors: {bl, bc, br}, track_id}], zones: [{zone_id, rule_hits, counts, active_rule, state, debounced_count, enabled, needs_review}], timings: {queue_wait_ms, decode_ms, infer_ms, rules_ms, total_ms}` |
| server -> browser | `frame_preview` | `camera_id, seq, bytes`, then one binary JPEG; never sent in privacy mode |
| server -> browser | `event` | `event`: the Event object (as in `GET /api/events`) |
| server -> browser | `camera_status` | `camera_id, session_id, status, last_seen_at, reason` |
| server -> browser | `metrics` | the `GET /api/metrics` payload, every `METRICS_INTERVAL_S` (2 s) |
| server -> browser | `error` | `code, message` (`bad_json`, `bad_message`, `bad_subscribe`, `unknown_type`) |
